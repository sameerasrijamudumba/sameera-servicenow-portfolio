## Project 01 — Automated Employee Access Request

### Challenge

Employee application-access requests required multiple manual approvals and repetitive coordination between IT teams.

### Solution

Developed a ServiceNow catalog-based request process that automatically routed requests through manager and application-owner approvals.

### Implementation

Used:

* Service Catalog
* Catalog Items
* Variables
* Client Scripts
* UI Policies
* Flow Designer
* Approval Actions
* Notifications

↓

Manager Approval

↓

Application Owner Approval

↓

IT Fulfillment

↓

Request Closure

### Outcome

Reduced manual coordination and provided users with better visibility into the status of their requests.
