# Phase 2 visual system

An enterprise ServiceNow developer portfolio, using only approved professional
content. Original workflow drawings communicate the work without employer assets.

- Canvas: near-black navy `#0b1117`; card surface `#101820`.
- Text: off-white `#f0f3f3`; secondary text `#9ba8b3`.
- Accent: restrained sage green `#9fd3b5`; borders `#26313b`.
- Typography: native Segoe UI / Arial sans-serif; Consolas for small technical labels.
- Layout: 1344px maximum container, 48px desktop gutters, 20px mobile gutters.
- Headings: up to 88px desktop hero, 43px small-screen hero; responsive 30–45px section headings.
- Surfaces: 6–12px radii, thin borders, minimal shadows; no neon or large glow.
- Header: 88px desktop, 76px mobile; navigation collapses below 1100px.
- Hero: two columns above 799px; stacked below. Workflow satellites simplify on small screens.
- Cards: four columns on desktop, two on mobile; 144px desktop minimum height, 32px desktop values, framed icons, and subtle hover lift.
- Motion: brief entrance/reveal, slow connector pulse and 3px node drift.
  Reduced-motion preference disables all animation, transitions, and smooth scrolling.
- Accessibility: visible focus, skip link, native disabled controls, semantic headings
  and lists. The menu is a nonmodal disclosure: Escape restores toggle focus; Tab may
  leave the menu; leaving the header closes it; hidden content is inert.
- Unbuilt sections remain visibly disabled. The resume has no URL until a real PDF
  is supplied. The workflow is explicitly a concept, not a live instance or project result.

Phase 2 includes only navigation, hero, workflow, highlights, and About preview.

## Phase 2 refinement

The desktop hero uses an approximately 54/46 split with 42px between columns,
18px supporting copy, 56px CTA controls, and 12px expertise badges. Workflow
nodes are 76px tall on desktop. The About preview pairs one concise paragraph
with a four-category capability panel; no separate Skills section was added.
Small-screen typography, icon placement, and panel spacing have independent rules.

## Phase 3 compositions

Technical Expertise uses a shared 3-column matrix, 2 columns on tablet, and 1 on
small phones. Experience pairs an employer identity rail with four responsibility
groups. Journey uses five connected capability markers horizontally on desktop
and vertically below 800px. Development Approach uses open numbered columns,
then a 2-column tablet grid and a vertical mobile flow. No dated milestone,
percentage, certification, or numerical outcome is implied.

## Phase 4 compositions

Alternating editorial project rows pair numbered case-study introductions with
original vertical workflow diagrams. Detail pages use a sticky contents rail on
desktop and a compact contents grid on mobile. Workflow labels remain at least
13px and wrap naturally. Styling follows existing navy, sage, and slate tokens.
Journey-to-Approach padding is tightened; internal verification labels are no
longer public. Approved hero/profile layouts are preserved.
